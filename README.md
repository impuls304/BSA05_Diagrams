# BSA05_Diagrams — Модели и диаграммы

Диаграммы потоков данных, межфункциональные диаграммы, диаграммы состояний и таблицы переходов для записи на услуги и доставки заказов.

Учебные работы по бизнес- и системному анализу. В репозитории представлены результаты выполнения; исходные условия заданий и учебные материалы не включены.
